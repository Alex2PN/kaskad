Быстрая установка
Подключитесь к вашему VPS (Ubuntu/Debian) под пользователем root и выполните одну команду:

wget -O install.sh https://raw.githubusercontent.com/Alex2PN/kaskad/main/install.sh && chmod +x install.sh && ./install.sh

Последующие запуски
При первой установке скрипт автоматически прописывается в систему. В дальнейшем, чтобы открыть меню, просто введите в терминале:

gokaskad

## 🚀 Быстрая установка

Подключитесь к вашему VPS (Ubuntu/Debian) под пользователем `root` и выполните одну команду:

```bash
wget -O install.sh https://raw.githubusercontent.com/dorofeev200/comp_maniya/main/install.sh && chmod +x install.sh && ./install.sh
```

### ⚡ Последующие запуски
При первой установке скрипт автоматически прописывается в систему. В дальнейшем, чтобы открыть меню, просто введите в терминале:
```bash
compmaniya
```
